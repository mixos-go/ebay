**Category:** Inventory_API
**API:** deleteInventoryItemGroup

**Method:** DELETE
**HTTP Path:** https://api.ebay.com{basePath}/inventory_item_group/{inventoryItemGroupKey}

## API Description
This call deletes the inventory item group for a given inventoryItemGroupKey value.

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| inventoryItemGroupKey (path) | string | Yes | This path parameter specifies the unique identifier of the inventory item group being deleted. This value is assigned by the seller when an inventory item group is created. |

## Response
_No documented response fields._
