**Category:** Post_Order_Case_Management_API
**API:** getCase

**Method:** GET
**HTTP Path:** https://api.ebay.com{basePath}/casemanagement/{caseId}

## API Description
Retrieve the details related to a specific case

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| caseId (path) | string | Yes | The unique identifier of a case. This URI parameter is required in order to identify the case for which an appeal will be filed against. The case is identified by the caseId that is passed in as part of the call URI. |

## Response
_No documented response fields._
