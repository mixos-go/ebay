**Category:** Post_Order_Return_API
**API:** getReturn

**Method:** GET
**HTTP Path:** https://api.ebay.com{basePath}/return/{returnId}

## API Description
Retrieve the details of a specific return

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| returnId (path) | string | Yes | The unique eBay-assigned ID of the return. The returnId value is required to identify the return for which a return shipping label is being created. |

## Response
_No documented response fields._
