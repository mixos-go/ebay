**Category:** Post_Order_Return_API
**API:** addShippingLabelInfo

**Method:** POST
**HTTP Path:** https://api.ebay.com{basePath}/return/{returnId}/add_shipping_label

## API Description
Create or update a shipping label provided by the seller

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| returnId (path) | string | Yes | The unique eBay-assigned ID of the return. The returnId value is required to identify the return for which a return shipping label is being created. |

## Response
_No documented response fields._
