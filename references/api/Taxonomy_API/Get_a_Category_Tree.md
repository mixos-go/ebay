**Category:** Taxonomy_API
**API:** Get_a_Category_Tree

**Method:** GET
**HTTP Path:** https://api.ebay.com{basePath}/category_tree/{category_tree_id}

## API Description
Get a Category Tree

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| category_tree_id (path) | string | Yes | The unique identifier of the eBay category tree. The category tree ID for an eBay marketplace can be retrieved using the getDefaultCategoryTreeId method. |
| Accept-Encoding (header) | string | No | This header indicates the compression-encoding algorithms the client accepts for the response. This value should be set to gzip . For more information, refer to HTTP request headers . |
