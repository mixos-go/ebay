**Category:** Taxonomy_API
**API:** Get_a_Category_Subtree

**Method:** GET
**HTTP Path:** https://api.ebay.com{basePath}/category_tree/{category_tree_id}/get_category_subtree

## API Description
Get a Category Subtree

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| category_id (query) | string | Yes | The unique identifier of the category at the top of the subtree being requested. Metadata on this category and all its descendant categories are retrieved. | category_tree_id (path) | string | Yes | The unique identifier of the eBay category tree. The category tree ID for an eBay marketplace can be retrieved using the getDefaultCategoryTreeId method. |
| Accept-Encoding (header) | string | No | This header indicates the compression-encoding algorithms the client accepts for the response. This value should be set to gzip . For more information, refer to HTTP request headers . |
