**Category:** Feed_API
**API:** getLatestResultFile

**Method:** GET
**HTTP Path:** https://api.ebay.com{basePath}/schedule/{schedule_id}/download_result_file

## API Description
This method downloads the latest Order Report generated by the schedule. The response of this call is a compressed or uncompressed CSV, XML, or JSON file, with the applicable file extension (for example: csv.gz). Specify the schedule_id path parameter to download its last generated file.

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| schedule_id (path) | string | Yes | This path parameter is the unique identifier of the schedule for which to retrieve the latest Order Report. Use the getSchedules method to retrieve schedule IDs. |

## Response
_No documented response fields._
