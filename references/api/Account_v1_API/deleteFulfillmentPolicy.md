**Category:** Account_v1_API
**API:** deleteFulfillmentPolicy

**Method:** DELETE
**HTTP Path:** https://api.ebay.com{basePath}/fulfillment_policy/{fulfillmentPolicyId}

## API Description
This method deletes a fulfillment policy. Supply the ID of the policy you want to delete in the fulfillmentPolicyId path parameter.

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| fulfillmentPolicyId (path) | string | Yes | This path parameter specifies the ID of the fulfillment policy to delete. This ID can be retrieved for a fulfillment policy by using the getFulfillmentPolicies method. |

## Response
_No documented response fields._
