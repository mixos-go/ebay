**Category:** Account_v1_API
**API:** createFulfillmentPolicy

**Method:** POST
**HTTP Path:** https://api.ebay.com{basePath}/fulfillment_policy/

## API Description
This method creates a new fulfillment policy for an eBay marketplace where the policy encapsulates seller's terms for fulfilling item purchases. Fulfillment policies include the shipment options that the seller offers to buyers. A successful request returns the getFulfillmentPolicy URI to the new policy in the Location response header and the ID for the new policy is returned in the response payload. Tip: For details on creating and using the business policies supported by the Account API, see eBay business policies .
